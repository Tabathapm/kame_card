# 🐉✨ Kame Card - Dragon Ball Z Card Game ✨🐉
 
Una aplicación web donde puedes coleccionar, comprar, vender, intercambiar y batallar cartas de personajes del universo Dragon Ball Z.

---

## 🚀 Características principales

- 🔐 **Autenticación de usuarios** (registro e inicio de sesión)
- 🃏 **Colección de cartas**: visualiza, filtra y explora tus cartas de personajes
- 🏪 **Tienda**: compra paquetes de cartas y monedas
- 🏷️ **Mercado**: compra, vende e intercambia cartas con otros jugadores
- ⚔️ **Batallas**: desafía a la CPU o a otros jugadores usando tus cartas
- 👤 **Perfil de usuario**: personaliza tu perfil y banner, revisa tus logros y actividad reciente
- 🔎 **Filtros avanzados**: busca por nombre, rareza, raza y afiliación
- 📖 **Modal de detalles**: explora información detallada de cada personaje

---

## 🛠️ Tecnologías utilizadas

- ⚛️ **React** + **TypeScript**
- ⚡ **Vite** (entorno de desarrollo rápido)
- 🎨 **Tailwind CSS** (estilos y diseño responsivo)
- 🖼️ **Lucide React** (iconos)
- 🌐 **API externa**: [dragonball-api.com](https://dragonball-api.com/) para obtener datos de personajes
